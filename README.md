# Galactik Manager (GFM)

Jeu de manager 7 contre 7 inspiré de *Galactik Football* — **projet de fan, gratuit et sans but lucratif**.
Le jeu tient dans une seule page web (`index.html`) : aucune installation, aucun serveur.

▶ **Jouer** : voir l’adresse GitHub Pages du dépôt (Settings → Pages).

## Bêta
- Les parties sont enregistrées **dans le navigateur** de chaque joueur (rien n’est envoyé en ligne).
- Pensez à **exporter** vos sauvegardes (Menu → Charger une partie → Exporter) avant une mise à jour.
- Un bug, une idée ? Bouton 💬 du menu du jeu, ou onglet **Issues** du dépôt.

*Fan game non officiel, réalisé avec Claude. Galactik Football appartient à ses ayants droit.*
